03 / Prepare Mesh & UVs

Good UVs, without
the manual repair work.

A procedural material can look correct in the viewport without usable UVs. MatricX Bake audits the actual bake layout before it ever starts.

Normal Mode

Best for simple and medium meshes. Uses Blender's own unwrap and packing tools — fast and reliable for common props.

Advanced Mode

Best for dense, subdivided, or overlap-prone meshes. Uses MinistryOfFlat when configured (Windows only).

With Auto-Fix Bake UVs enabled, MatricX Bake detects missing UVs, zero-area faces, stacked or overlapping faces, and coordinates outside the 0–1 tile. When the active layout is unsafe, it creates a dedicated MX_BakeUV and leaves your original UV layer untouched.

06 / Built to Work With MatricX Pro

Procedural imperfections
survive the bake.

Joining objects normally breaks procedural masks. MatricX Bake stops that from happening.

MatricX Pro's imperfection layers frequently use Object or Generated coordinates inside nested node groups. MatricX Bake stores each source object's original coordinates and substitutes them only on temporary copied materials — so dirt, wear, noise, bump and layered Mix Shader masks keep their original placement. Your source materials and node groups are never modified.

Channel-consistent flattening compensation keeps MatricX Dirt from replacing broad metal regions with brown dielectric color, and keeps Edge Wear from baking stronger than the source material — while other Mix Shader materials use standard linear conversion.

09 / Decals & Export

From baked material
to shipped asset.

Decals

Bake Scene Decals

Bakes decal meshes into the active target's UVs. In One Texture Set mode, decal baking targets the full bake scope and writes into the same shared atlas as the material maps.

Combine

Combine Decal & Material

Blends Base Color, Roughness, Metallic and Normal using the decal mask into one new PBR material. Combine Set & Apply to All assigns it across every receiver mesh automatically.

Final Bake

Flatten to Export-Ready Maps

Flattens the current material into a simplified texture set after combining decals, or whenever a flattened game-ready result is needed.

Export

Game Asset Export

Packages the model, textures and an asset_manifest.json file. Supports FBX and GLB depending on your export settings.

12 / Before You Buy

The things
you should know.

Do I need MatricX Pro to use MatricX Bake?

No. MatricX Bake works with any Blender material. It includes extra compensation specifically for MatricX Pro's procedural imperfection layers, but that's a bonus, not a requirement.

Can it bake multiple objects into one texture?

Yes — One Texture Set mode shares one atlas and one set of maps across every mesh in the bake scope.

What if my UVs are messy or missing?

Auto-Fix Bake UVs detects missing UVs, zero-area faces, stacked or overlapping faces, and out-of-tile coordinates, then creates a dedicated bake UV automatically. Your original UV layer is left untouched.

Does it support glass and refractive materials?

Yes, with the understanding that baked PBR maps can't perfectly recreate live refraction or caustics. Base Color with Include Scene Lighting, plus Roughness, Normal and Opacity, gets the closest visual match.

What export formats are supported?

FBX and GLB, packaged together with your textures and an asset_manifest.json file.

Does the advanced UV mode work on macOS or Linux?

The MinistryOfFlat-powered Advanced mode is Windows-only. On macOS and Linux, Normal UV mode is used instead, and every other workflow — material, decal, final bake, packing and export — remains fully available.

Which Blender versions are supported?

Blender 4.5 and 5.0 or newer, with 5.1 and 5.2 specifically tested.
