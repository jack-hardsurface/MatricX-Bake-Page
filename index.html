One Texture Set
for the Whole Asset

Bake every part of a model — selected objects or a whole collection — into one shared atlas, one material and one set of maps.

  • Pack the islands you already have, or rebuild a clean shared atlas
  • Every part keeps its own rotation, scale and mirroring, so procedural wear looks the same as in your viewport

Your UVs
Stay Yours

Bake checks every UV map before it bakes. Overlapping, stacked, zero-area or out-of-tile UVs get a dedicated bake UV (MX_BakeUV) — your own UV map is never replaced.

  • Normal UV Unwrap for simple meshes; Advanced UV Unwrap with MinistryOfFlat for dense ones (Windows)
  • MatricX PRO trim faces keep their exact place on the trim sheet
  • Every bake step hands your active UV map back afterwards

Decals,
Baked In

Floating decals don't survive an export. Bake them straight into the texture set of the mesh they sit on.

  • Auto-Detect finds MatricX PRO and DECALmachine decals parented to your model
  • Combine Decal & Material blends the decal maps over the base maps
  • Final Bake flattens everything into one finished texture set

Export

FAQ

Questions, Answered

Is $49 the permanent price?

No. $49 is the launch price. The regular price is $79.

Do I need MatricX PRO?

No. MatricX Bake bakes any Blender material. It also has built-in support for MatricX PRO 2.1: all 16 imperfections, every material family, its glass and its trim sheets.

Can I bake several objects into one texture?

Yes. Set the scope to Selected Objects or a Collection and the Texture Set to One Texture Set. Every part shares one atlas and one material, and keeps its own rotation and scale while baking.

Do my UVs have to be perfect?

No. Leave Auto-Fix Bake UVs on: when a UV map overlaps or is stacked, MatricX Bake creates a separate bake UV and keeps yours untouched. Step 1 can also unwrap for you.

Which game engines does the export support?

Game Asset Export writes FBX or GLB with presets for Unity, Unreal Engine and Godot, plus a Generic preset. The baked UV is UV channel 0 and every map is copied beside the model.

How do decals end up in the texture?

Bake Scene Decals bakes decals parented to (or selected with) your model into its UV space. Combine Decal & Material layers them over your maps, and Final Bake flattens the result.

Does it run on macOS and Linux?

Yes — it is pure Python on Blender's own APIs, one build for every system. The optional Advanced UV Unwrap uses MinistryOfFlat, which is Windows-only; on macOS and Linux it uses Blender's built-in unwrap.

Add-on or Extension — which do I install?

Either; they are the same tool. Install one, not both. The Extension uses Blender's Get Extensions installer, the Add-on uses the classic Add-ons installer.
